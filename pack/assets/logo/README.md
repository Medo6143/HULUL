# Logo

Source (verified by opening the live site in a browser and reading the DOM):

- File: `/icons/nav-logo.png` on https://hulol-tech.vercel.app
- Full URL: https://hulol-tech.vercel.app/icons/nav-logo.png
- Type: PNG, 500 x 500 px, about 124 KB, used in the navbar at 32 px
- Alt text on the old site: "HULOL TECH Logo"

Rules:

1. Use the logo exactly as it is. Do not redraw, recolor or crop it.
2. The original file could not be copied into this pack from the build environment (the network policy blocked the download), so it is not bundled here. Get it with either option:
   - run `bash assets/logo/fetch-logo.sh` from your machine, or
   - copy `public/icons/nav-logo.png` from the old site repository.
3. Prefer a vector (SVG) or a larger PNG if the design team has one. The 500 px PNG is fine up to about 160 px display width.
4. Final location in the new project: `public/icons/nav-logo.png` (and `public/icon.png`, `public/apple-touch-icon.png` for favicons, generated from it).
