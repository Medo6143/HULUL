# حزمة مشروع موقع حلول تك (HULOL TECH)

موقع Next.js + Firebase، عربي افتراضي وإنجليزي، يستهدف السوق الخليجي (السعودية أولاً)، يجذب العملاء ويدير رحلتهم: **الاستشارة، ثم البروبوزل، ثم العمل، ثم الدعم بعد الاستلام**. بدون إيموجي، وبدون أسعار معلنة (الاستشارة المجانية أولاً).

## قرارات ثابتة

1. بدون إيموجي في أي مكان، الأيقونات SVG فقط (يفرضه CI).
2. اللوجو من الموقع القديم بدون تعديل.
3. عربي افتراضي ومرجعي، إنجليزي ترجمة.
4. لا أسعار معلنة. سؤال الميزانية اختياري، والعرض المكتوب بعد الاستشارة (مراجعة القرار بالأرقام بعد 90 يوم).
5. لا كتابة مباشرة من المتصفح لقاعدة البيانات، كل الكتابات عبر الخادم.
6. المرحلة 1: الموقع + الطلب + الأدمن + القياس. المرحلة 2: البروبوزل + بوابة العميل + المشاريع + الدعم.

## ما ينقص ولا يمكن اختلاقه

اللوجو الأصلي (يُسحب بالسكربت)، السجل التجاري، رقم الضريبة، العنوان الوطني، الدومين، 3 دراسات حالة وآراء العملاء بموافقتهم، لقطات المشاريع، التزامات الـ SLA النهائية، نطاقات سؤال الميزانية، ومراجعة قانونية. قائمتها التفصيلية في `06-content-and-compliance/01-content-checklist.md`.

## صدق الأرقام

كل رقم في الخطة موسوم بمصدره أو بأنه تقدير. أرقام الأسعار من مدونات شركات وتُستخدم كمرجع داخلي فقط. مؤشرات الأداء (KPI) افتراضات تخطيط تُستبدل بخط أساس حقيقي بعد 30 يوم من النشر.
